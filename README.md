# VERSUS

중세 무사 대전 격투 웹 앱(PWA). 기획은 `../proposal/`, 구현 계획은 `../docs/plan.md`, 승인된 컨셉 아트는 `../concept/index.html`에 있습니다.

## 실행

이 `src/` 폴더가 앱 루트입니다. 빌드 없이 정적 파일로 동작합니다. 서비스 워커와 ES 모듈 때문에 HTTP로 서빙해야 합니다.

```sh
cd src
npm run serve        # http://localhost:8080 (같은 Wi-Fi의 태블릿용 주소도 출력, no-cache 헤더)
npm run serve:https  # https://<IP>:8443 자체 서명 인증서 (태블릿에서 컨트롤러·오프라인을 시험할 때)
npm test             # 순수 로직 테스트 (node --test)
npm run build:sprites  # tools/art 리그로 themes/classic 스프라이트 재생성
npm run build:sfx      # 효과음 합성 → sfx/*.wav
```

렌더링·사운드는 [Phaser 4](https://phaser.io) (`vendor/phaser-4.2.1.esm.min.js`, MIT)를 빌드 없이 ES 모듈로 불러온다. 게임 규칙(`config/fighter/combat/game/ai`)은 Phaser와 독립된 순수 로직이고, `js/stage.js`가 그 상태를 읽어 그리면서 파티클, Arcade 물리 파편, 카메라 흔들림·플래시, 글로우 필터, 효과음을 더한다.

### 태블릿에서 테스트할 때

- 서비스 워커(오프라인·설치)는 **HTTPS 또는 localhost**에서만 동작한다. `http://192.168.x.x:8080`으로 열면 PWA 기능 없이 일반 페이지로 돈다. 브라우저에 따라 **컨트롤러(Gamepad API)도 보안 연결에서만** 열린다. 타이틀 아래 안내에 "보안 연결(HTTPS)이 아니라…"가 보이면 이 경우다.
- `npm run serve:https`는 openssl로 자체 서명 인증서를 한 번 만들어 프로젝트 루트의 `.cert/`(앱 폴더 밖)에 둔다. Safari 경고에서 "세부사항 보기 → 이 웹 사이트 방문"으로 들어간다. Mac의 IP가 바뀌면 `.cert/`를 지우고 다시 실행한다.
- 오류가 나면 화면 아래에 빨간 오류 상자가 뜬다. 내용을 그대로 알려주면 원인을 찾을 수 있다. **앱 새로 받기**를 누르면 서비스 워커와 캐시를 지우고 서버에서 다시 받는다.
- 타이틀 화면의 버전 표시(`v12`)로 어떤 버전이 실행 중인지 확인한다.
- Safari는 컨트롤러 버튼을 한 번 눌러야 페이지에 컨트롤러를 알려준다.

## 캐릭터별 특수 규칙

- 청룡언월도(칭기즈 칸): 앞, 앞(홀드)으로 기마 돌진 — 단검 순간이동 거리(240px)를 0.3초에 질주한다. 데미지는 없고, 돌진 중엔 필살기와 공중 공격 말고는 맞지 않는다.
- 창 필살기(일섬 돌격): 예전의 1.5배(405px)를 전진하며, 끝날 때 키의 0.8배 높이까지 비스듬히 올라간다.

- 칼: 공중 공격은 일반 공중 공격이다(v10의 수직 내려찍기는 없앴다). 버티기 공격(뒤+공격) 중에는 데미지를 아예 받지 않는다(필살기는 예외). 버티기 공격이 맞으면(막히지 않고) 바로 다음 공격 한 번이 1.5배 빠르다.
- 창: 점프 공격·전진 공격 리치 1.3배, 버티기 공격 리치는 평타와 같음.
- 단검: 앞 방향을 빠르게 두 번 눌러 두 번째를 유지하면 앞으로 키의 3배(240px) 순간이동(그림자 걸음, 0.5초 재사용 대기).
- 철퇴: 전진 공격도 맞아도 끊기지 않음(데미지는 받음), 버티기 공격 리치는 평타와 같음.
- 갈퀴: 황소 데미지 80.
- 채찍(카우보이): 리치 105(가장 긴 140의 3/4), 파워 8.8(가장 센 22의 2/5), 속도 3/5(가장 빠른 맨손 0.27초 → 한 번 휘두르는 데 0.45초 = 0.17+0.10+0.18). 버티기 공격이 없어 뒤+공격은 평타다. 2단 점프가 있고, 2단 점프 중 공격하면 그 자리에 멈춰 45° 아래 앞으로 채찍(리치 1.5배 = 157.5px)을 내리친다(2단 점프당 한 번, 데미지는 공중 공격과 같음). 차징 공격은 권총: 0.45초 장전(활 0.3초보다 김) 후 화살과 같은 속도(620px/s)로 손 높이에서 수평으로 키의 3.5배(280px)까지 날아가고 거기서 뚝 떨어진다(떨어지는 총알은 데미지 없음). 데미지는 평타의 1.5배(13), 방어를 깨뜨린다. 뒤 방향을 빠르게 두 번 눌러 두 번째를 유지하면 채찍을 뒤쪽 땅에 걸고 당겨 0.2초 동안 키의 2배(160px) 뒤로 빠진다(갈고리 후퇴, 0.5초 재사용 대기).

## 기술 일람표

대전 설정에서 컨트롤러 Ⓑ를 누르면 그 패드 커서가 있는 쪽 캐릭터 선택 영역 전체에 기술표 팝업이 뜬다(커서가 캐릭터 위에 있으면 그 캐릭터, 아니면 선택된 캐릭터). 고정 크기이고 ▲▼로 안을 스크롤하며, 같은 Ⓑ로 닫는다. 터치(또는 마우스)로는 이미 선택된 캐릭터를 한 번 더 누르면 같은 팝업이 뜨고, 손가락으로 밀어 스크롤하며 우상단 ✕ 버튼으로 닫는다. 설정 화면에서 뒤로 가기는 컨트롤러 Select. 기술 이름과 입력은 `js/moves.js`에 있다.

## 회복 모드 (보급)

대전 설정의 **회복 아이템** 버튼으로 없음 → 보급 → 보급x2를 고른다. 보급을 켜면 20초마다 지금 보이는 화면 안 무작위 위치로 맵에 어울리는 운반자가 회복 아이템을 매달고 내려온다(초원 독수리·사과, 달 기지 위성·건전지, 이집트 태양신·물단지, 용암 박쥐·군고구마, 밀림 앵무새·바나나, 서울 드론·삼각김밥, 툰드라 올빼미·생선, 판옥선 가오리연·주먹밥, 도서관 종이비행기·바나나우유, 로마 독수리·포도, 전통시장 까치·붕어빵). 2층 발판 위로 떨어지면 거기 놓이고, 내려앉으면 운반자는 날아가고 아이템은 2초 동안 깜빡이다 사라진다. 닿은 캐릭터는 체력이 10% 오른다. 보급x2에서는 두 번에 한 번 20% 회복 아이템이 나오며 더 크고 빛난다.

메뉴(타이틀·대전 설정·일시정지·결과)도 게임패드와 키보드로 조작한다: 방향키/스틱으로 커서 이동, Ⓐ·Enter 선택, Ⓑ·Esc 뒤로, ☰ Start로 대전 시작. 설정 화면에서 커서는 움직이기만 하고 캐릭터·맵은 Ⓐ를 눌러야 바뀐다. LB/RB로 맵을 넘긴다. 2인 대전에서 두 번째 패드는 P2 캐릭터 칸 안에서 자기 커서(빨간 점선)를 움직이고 Ⓐ로 고른다. 표준 배열이 아닌 컨트롤러(d-pad가 축으로 오는 경우)도 읽는다. 패드가 연결되면 화면 아래에 버튼 안내가 나온다.

게임패드는 연결된 순서대로 P1, P2에 배정되고, 배정된 플레이어의 터치 버튼은 화면에서 사라집니다(컴퓨터 쪽 버튼도 원래 없음). 터치 버튼이 하나도 남지 않으면 메인 화면이 그만큼 커져 화면을 채우고, 대전 중에 패드를 꽂거나 뽑아도 바로 다시 배치됩니다.

## 전투 규칙

- 방어는 무기마다 올라오는 시간(`guardUp`)이 다르다. 무거운 무기일수록 느리고, 다 올라오기 전에 맞으면 그대로 맞는다.
- 점프 공격은 데미지 1.5배. 공중에 떠 있는 동안 받는 공격은 33% 확률로 회피한다.
- 방향 전환: 두 캐릭터가 서로 넘어가 교차하면 0.5초 뒤에 돌아선다. 그 사이 공격이나 방어를 누르면 즉시 돌아선 상태로 판정한다.
- 차징 공격: 공격을 길게 누르면 첫 타는 평타로 나가고, 끝나자마자 0.3초 모은 뒤 한 번 더 친다(도중에 떼면 취소). 모으는 동안 노란 기가 몸으로 모여들고 차징 효과음이 울리며, 둘 다 정확히 0.3초에 끝난다(장전이 더 긴 권총은 소리를 늘여 장전 끝에 맞춘다). 이 공격은 방어를 깨뜨린다. 방어 중인 상대는 데미지 절반을 받고 잠깐 경직되며, 필살기 게이지가 2 오른다. 막지 않았을 때 데미지는 평타와 같다.
- 공중 회피: 공중에 떠 있는 동안(점프·낙하·공중 공격 모두) 상대 공격을 33% 확률로 피한다. 내 공격 종류와는 상관없다.
- 긴 공격: 앞으로 걸으며 공격하면 평타보다 1.2배 느리지만 모든 캐릭터가 똑같이 리치 +19px(평균 보폭 37.9px의 절반)를 얻고, 그와 별개로 공격 중에도 앞으로 계속 걷는다.
- 리치가 가장 긴 캐릭터의 절반(70) 이하인 도끼·단검·맨손·발차기와 카우보이는 2단 점프(공중제비)를 쓴다. 2단 점프 중 공격하면 45°로 내리꽂는다(맨손 날라차기, 단검 칼날찌르기, 도끼 내려찍기; 카우보이는 내리꽂지 않고 공중에 멈춰 45° 채찍질). 데미지는 공중 공격과 같다.
- 그보다 리치가 긴 칼·창·큰 턱·청룡언월도·철퇴·갈퀴(궁수 포함, 카우보이 제외)는 뒤로 걸으며 공격하면 묵직한 공격이 나간다. 리치는 0.8배지만 공격 중에 맞아도 데미지만 받고 넉백·경직 없이 계속 공격한다(필살기는 막지 못함). 데미지는 평타와 같다. 칼은 이때 데미지도 받지 않는다.
- 라운드 시작: "ROUND n"이 떠 있는 동안 두 캐릭터 초상화가 양쪽에서 들어오고, 가운데 "VS"가 불꽃과 번개를 두르고 내리꽂힌다(라운드 소개 시간 1.6초는 그대로).
- 필살기를 쓰면 화면이 사용자 쪽으로 클로즈업되고 배경이 어두워지며 위아래 시네마 바가 들어온다. 필살기가 끝나면 원래 화면으로 돌아온다.
- 판정 유예 0.05초: 공격이 닿은 뒤 0.05초 후에 확정된다. 그 사이 방어를 누르고 있으면(완전히 올라오지 않았어도) 방어로 처리되고, 상대 공격도 그 사이에 닿으면 둘 다 맞는다(동시타격).
- 패링: 확정 시점 전 0.1초 안에 방어 버튼을 **새로 누르면**(계속 누르고 있던 것은 해당 없음) 데미지 없이 막고, 공격한 쪽은 0.2초 굳는다(푸른빛, "패링!" 금속음). 화살·총알도 패링된다. 필살기, 방어 무시 공격, 잡기(올가미 포함)는 패링되지 않는다. 공격 중이거나 경직 중이면 패링할 수 없다. 컴퓨터도 가끔(쉬움 2%, 어려움 6% 확률로 노려서) 패링한다.
- 타격 순간 짧게 멈추는 히트스톱이 있다(데미지에 비례, 최대 0.12초).
- 필살기 게이지: 맞으면 +3, 방어에 성공하면 +1, 최대 20. 필살기를 쓰는 동안에는 무적이다. 게이지를 모으는 동안(공격+방어 유지) 푸른 불꽃이 점점 커진다.

태권도는 모든 공격이 발차기다: 평타 앞차기, 앞+공격 돌려차기, 뒤+공격 내려찍기(다리를 머리 높이로 든 채 0.2초 멈췄다가 찍음, 버티기), 차징 뒷차기(몸을 돌려 등을 보인 채 뒤로 참), 2단 점프 중 공격 날라차기. 리치·파워는 단검과 같고 속도는 단검과 맨손 사이다.

궁수는 칼과 같은 스탯으로 환도를 쓰고, 뒤+공격은 횡베기(버티기)다. 차징 공격은 활쏘기로 바뀐다: 0.3초 장전 후 메인 뷰 가로의 2/3(약 427px)까지, 캐릭터 키의 1.2배 높이를 지나는 곡사로 날아가며 평타의 1.5배 데미지를 준다(차징 공격이라 방어를 깨뜨린다).

사슴벌레의 2단 점프는 위가 아닌 진행 방향으로 수평 돌진한다(210px, 0.26초). 돌진 중엔 상대 공격을 받지 않지만 공격도 못 하고, 끝나기 0.06초 전부터 공중 공격이 가능하다.

수치는 `js/config.js`의 `WEAPONS`, `SUPERS`에 있다.

## 터치 조작

이동은 가상 조이스틱이다. 옆으로 밀면 걷고, 위로 세게 밀면 점프, 아래로 세게 밀면 2층에서 내려간다. 버튼 하나를 누른 채 같은 플레이어의 다른 버튼으로 미끄러지면 두 버튼을 함께 누른 것으로 친다(공격 → 방어로 밀면 공격+방어, 필살기 입력에 쓸 수 있다).

## 컴퓨터

컴퓨터는 약 20초(16~24초)마다 한 번씩 거리를 벌릴지 정한다. 쉬움은 70%, 어려움은 30% 확률로 1.2~2초 동안 뒤로 물러난다(뒤에 함정이 있으면 뛰어넘고, 공격이 오면 막는다).

## 함정 애니메이션

함정은 8프레임이다. 계속 움직이는 함정은 프레임마다 위상이 0→1→0으로 이어져 부드럽게 돌고, 사람이 들어와야 반응하는 함정(도서관 경비, 전통시장 대게, 초원 악어)은 평소 4프레임, 반응 4프레임(흔들림)을 쓴다.

## 테마 추가

`themes/<id>/theme.json`에 무기 슬롯(sword, spear, axe, dagger, fist, stag, genghis, mace, fork, tkd, archer, whip)별 캐릭터 스프라이트 시트와 프레임 아틀라스, 맵(lava, jungle, seoul, tundra, ship, library, rome, egypt, savanna, market, moon)별 레이어 이미지를 정의합니다. 구조는 `themes/classic/theme.json`과 같고, 이미지는 SVG와 PNG 모두 쓸 수 있습니다. 게임 수치와 맵 변수는 `js/config.js`에 있습니다.
