# VERSUS

중세 무사 대전 격투 웹 앱(PWA). 기획은 `../proposal/`, 구현 계획은 `../docs/plan.md`, 승인된 컨셉 아트는 `../concept/index.html`에 있습니다.

## 실행

이 `src/` 폴더가 앱 루트입니다. 빌드 없이 정적 파일로 동작합니다. 서비스 워커와 ES 모듈 때문에 HTTP로 서빙해야 합니다.

```sh
cd src
npm run serve        # http://localhost:8080 (같은 Wi-Fi의 태블릿용 주소도 출력, no-cache 헤더)
npm test             # 순수 로직 테스트 (node --test)
npm run build:sprites  # tools/art 리그로 themes/classic 스프라이트 재생성
npm run build:sfx      # 효과음 합성 → sfx/*.wav
```

렌더링·사운드는 [Phaser 4](https://phaser.io) (`vendor/phaser-4.2.1.esm.min.js`, MIT)를 빌드 없이 ES 모듈로 불러온다. 게임 규칙(`config/fighter/combat/game/ai`)은 Phaser와 독립된 순수 로직이고, `js/stage.js`가 그 상태를 읽어 그리면서 파티클, Arcade 물리 파편, 카메라 흔들림·플래시, 글로우 필터, 효과음을 더한다.

### 태블릿에서 테스트할 때

- 서비스 워커(오프라인·설치)는 **HTTPS 또는 localhost**에서만 동작한다. `http://192.168.x.x:8080`으로 열면 PWA 기능 없이 일반 페이지로 돈다.
- 오류가 나면 화면 아래에 빨간 오류 상자가 뜬다. 내용을 그대로 알려주면 원인을 찾을 수 있다. **앱 새로 받기**를 누르면 서비스 워커와 캐시를 지우고 서버에서 다시 받는다.
- 타이틀 화면의 버전 표시(`v6`)로 어떤 버전이 실행 중인지 확인한다.
- Safari는 컨트롤러 버튼을 한 번 눌러야 페이지에 컨트롤러를 알려준다.

## 조작

| 행동 | 터치 | 키보드 P1 / P2 | 게임패드 |
|---|---|---|---|
| 이동 | ◀ ▶ | A D / ← → | 방향키·왼쪽 스틱 |
| 점프 | 점프 | W / ↑ | 위 |
| 2층에서 내려가기 | – | S / ↓ | 아래 |
| 공격 | 공격 | F / K | A |
| 방어(누르고 있기, 천천히 이동 가능) | 방어 | G / L | B |
| 긴 공격 | ▶(앞으로) 누른 채 공격 | 앞+F / 앞+K | 앞+A |
| 묵직한 공격(리치 긴 캐릭터) | ◀(뒤로) 누른 채 공격 | 뒤+F / 뒤+K | 뒤+A |
| 2단 점프(리치 짧은 캐릭터) | 공중에서 점프 | W / ↑ | 위 |
| 내리꽂기 | 2단 점프 중 공격 | F / K | A |
| 필살기(게이지 MAX에서 1초 유지) | 공격+방어 동시에 | F+G / K+L | A+B |
| 일시정지 | ❚❚ 버튼 | Esc / P | Start |
| 메뉴로 나가기 | ⌂ 버튼 (확인 후 나감) | – | Select |

메뉴(타이틀·대전 설정·일시정지·결과)도 게임패드와 키보드로 조작한다: 방향키/스틱으로 이동, Ⓐ·Enter 결정, Ⓑ·Esc 뒤로, ☰ Start로 대전 시작. 설정 화면에서 캐릭터·맵은 커서를 올리면 바로 선택되고, LB/RB로 맵을 바꾼다. 2인 대전에서 두 번째 패드는 ◀▶로 P2 캐릭터를 바로 고른다. 패드가 연결되면 화면 아래에 버튼 안내가 나온다.

게임패드는 연결된 순서대로 P1, P2에 배정되고, 배정된 플레이어의 터치 버튼은 흐리게 비활성화됩니다.

## 전투 규칙

- 방어는 무기마다 올라오는 시간(`guardUp`)이 다르다. 무거운 무기일수록 느리고, 다 올라오기 전에 맞으면 그대로 맞는다.
- 점프 공격은 데미지 1.5배. 공중에 떠 있는 동안 받는 공격은 33% 확률로 회피한다.
- 공중 회피: 공중에 떠 있는 동안(점프·낙하·공중 공격 모두) 상대 공격을 33% 확률로 피한다. 내 공격 종류와는 상관없다.
- 긴 공격: 앞으로 걸으며 공격하면 평타보다 1.2배 느리지만 모든 캐릭터가 똑같이 리치 +19px(평균 보폭 37.9px의 절반)를 얻고, 그와 별개로 공격 중에도 앞으로 계속 걷는다.
- 리치가 가장 긴 캐릭터의 절반(70) 이하인 도끼·단검·맨손은 2단 점프(공중제비)를 쓴다. 2단 점프 중 공격하면 45°로 내리꽂는다(맨손 날라차기, 단검 칼날찌르기, 도끼 내려찍기). 데미지는 공중 공격과 같다.
- 그보다 리치가 긴 칼·창·큰 턱·청룡언월도는 뒤로 걸으며 공격하면 묵직한 공격이 나간다. 리치는 0.8배지만 공격 중에 맞아도 데미지만 받고 넉백·경직 없이 계속 공격한다(필살기는 막지 못함). 데미지는 평타와 같다.
- 필살기를 쓰면 화면이 사용자 쪽으로 클로즈업되고 배경이 어두워지며 위아래 시네마 바가 들어온다. 필살기가 끝나면 원래 화면으로 돌아온다.
- 판정 유예 0.05초: 공격이 닿은 뒤 0.05초 후에 확정된다. 그 사이 방어를 누르고 있으면(완전히 올라오지 않았어도) 방어로 처리되고, 상대 공격도 그 사이에 닿으면 둘 다 맞는다(동시타격).
- 타격 순간 짧게 멈추는 히트스톱이 있다(데미지에 비례, 최대 0.12초).
- 필살기 게이지: 맞으면 +3, 방어에 성공하면 +1, 최대 20. 필살기를 쓰는 동안에는 무적이다.

| 캐릭터 | 무기 | 필살기 |
|---|---|---|
| 알드릭 | 칼 | 성검 십자참 — 짧게 돌진하며 2연속 베기 |
| 이운 | 창 | 일섬 돌격 — 직선으로 길게 돌진하며 찌르기 |
| 비요른 | 도끼 | 대지 분쇄 — 긴 사거리 내려찍기, 방어 무시 |
| 자라 | 단검 | 그림자 습격 — 상대 뒤로 순간이동 후 4연속 찌르기, 방어 무시 |
| 혜명 | 맨손 | 백열권 — 10연타 후 마무리 일격 |
| 루카누스 | 큰 턱 | 집게 내던지기 — 집어 공중으로 던짐, 방어 무시 |
| 칭기즈 칸 | 청룡언월도 | 기마 돌격 — 말을 타고 화면을 가로지르는 돌격, 방어를 깨뜨림 |

수치는 `js/config.js`의 `WEAPONS`, `SUPERS`에 있다.

## 테마 추가

`themes/<id>/theme.json`에 무기 슬롯(sword, spear, axe, dagger, fist, stag, genghis)별 캐릭터 스프라이트 시트와 프레임 아틀라스, 맵(lava, jungle, seoul, tundra)별 레이어 이미지를 정의합니다. 구조는 `themes/classic/theme.json`과 같고, 이미지는 SVG와 PNG 모두 쓸 수 있습니다. 게임 수치와 맵 변수는 `js/config.js`에 있습니다.
